Project · editor

Vela

Vela: Latin for “sails”, and a constellation of the southern sky.

Agents now write a growing share of the code. Vela is where you run them: one space per task, with its repos, its links and its agents, each agent in its own worktree. They propose, you decide, and nothing reaches your code without you.

  • Agents propose, you decide

    Each agent works in its own worktree and proposes hunks. Accept, reject or edit each one: you stay the author of every line that ships.

  • Every agent, one cockpit

    Claude Code, Codex, opencode, Gemini CLI, Crush: bring the ones you use. Vela handles everything around them: worktrees, review, checks, commits.

  • “Up next”

    Vela always shows the single most useful action: answer an agent, review a proposal, commit. Enter does it.

  • Made for developers

    Keyboard first: every action has a key, Ctrl K reaches everything, Ctrl P opens any file. Git runs as in your terminal, with your hooks and your config.

  • Review that checks for you

    Staged files, diff and checks (hooks, lint, types, tests) in one view. Checks rerun on their own when what you stage changes, and never twice on the same tree.

  • Commits worth reading

    Vela proposes the commits: conventional type and scope from the diff, a split when one diff is really three, the ticket in the footer.

Source code In active development, no release yet. Follow along on GitHub.

Project · browser

Sillage

Sillage: French for “wake”, like the tail a comet leaves behind it.

Inspired by Arc, Sillage gives Firefox a vertical sidebar, workspaces, profiles and a command palette. It is not a fork: it installs the official Mozilla release and adds its interface at startup, so the engine, security updates, extensions and Firefox Sync stay those of Firefox.

  • Workspaces and profiles

    Each workspace has its own color, pinned tabs and profile (a Firefox container): two Google accounts side by side, in a single window.

  • Command palette

    URLs, search, open tabs, history and commands in one field, with the best match filled in as you type. Ctrl T.

  • Board

    Each workspace has an infinite canvas for notes, text, shapes and links. Notes expire and remind you, and an empty workspace opens on its board, never on a blank page.

  • Glance

    A link opens in a card over the page. Keep it as a tab, or close it and carry on.

  • Synced and encrypted

    Workspaces, pinned items, boards and profiles follow you through Firefox Sync, end-to-end encrypted.

  • Light and quiet

    Tabs load when you open them, cookie banners are refused for you, and Sillage sends nothing of its own apart from a daily check for new Firefox releases on macOS.

Install (Linux x86_64 or macOS)

git clone https://github.com/khaalipso/sillage.git
cd sillage
make install
make launch

Questions

Can I use Vela today?

Not yet. Vela is still under construction and has no release. The source code is on GitHub.

Which coding agents does Vela work with?

Claude Code, Codex, opencode, Gemini CLI and Crush. Vela drives these existing tools and handles what surrounds them: worktrees, review, checks and commits.

Can an agent change my code without me?

No. Agents work in their own worktree and propose hunks. You accept, reject or edit each one before it reaches yours.

What happens to my work if I stop using Vela?

Nothing is lost. Spaces are git branches and standard git worktrees, so any git tool can still read them.

Is Sillage a Firefox fork?

No. Sillage installs an unmodified Mozilla release and injects its interface at startup. The engine, security updates, extensions and Firefox Sync stay those of Firefox.

Which systems does Sillage run on?

Linux x86_64 and macOS.

Does Sillage send my data anywhere?

Your workspaces and boards are stored in your Firefox profile. Sillage makes no network requests of its own beyond search suggestions from your default search engine (when enabled in Firefox), Firefox Sync when you are signed in, and, on macOS, a daily check for new Firefox releases.

How do I report a bug or suggest an idea?

Open an issue on khaalipso/vela or khaalipso/sillage. Contributions are welcome.
